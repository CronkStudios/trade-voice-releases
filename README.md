# Trade Voice downloads

Trade Voice is a trading journal you speak instead of write: talk through your
session, and get a tagged transcript and a coaching summary afterwards.

**Download the latest version from [Releases](https://github.com/CronkStudios/trade-voice-releases/releases/latest):**

- **Mac** (Apple Silicon): `TradeVoice-…-mac-arm64.dmg`. Open it and drag Trade Voice into Applications.
- **Windows**: `TradeVoice-…-win-x64.exe`. Run it. Windows may say "Windows protected your PC" the first time:
  click **More info**, then **Run anyway**.

You need an invite code to use it. Once installed, Trade Voice updates itself.

This repository only holds the installers.
